# NOVIRA-26 | Hospital Research Network

Four fictional hospitals have analyzed **2,400 synthetic patient records**.

## Project files
- `NOVIRA26_cleaned.csv` — cleaned patient data.
- `analyse_novira26.py` — Python script to reproduce the statistical results.
- `index.html` — hospital website containing the verified results.
- `README.md` — this guide.

## Your mission
1. Open `index.html` in a web browser. **Keep the published statistics unchanged.**
2. Complete the **Final scientific report** with your own short conclusion, explaining why the interpretation of the treatment comparison changed.
3. Add a graph illustrating this finding directly inside `index.html` (no additional file required). You may use AI for technical HTML assistance, but **not to write the scientific interpretation**.
4. Use **Git** to track the project: create the repository and first **commit**, work on a **branch**, make further **commits**, and **merge** the completed work into `main`.
5. Publish your four project files in a **public GitHub repository** with the commit history visible. Complete the teacher's **Google Form** to submit your assignment.

*All patient data and treatments are fictional. Observational results do not establish treatment efficacy.*
